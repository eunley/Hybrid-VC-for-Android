# Contributing / 贡献

Original project code is MIT. Contributions must preserve third-party attribution and applicable licenses. No CLA or DCO is imposed by this draft.

原创代码采用 MIT。提交者应确保代码、翻译、图标、模型和音频拥有合法授权；禁止提交密钥、个人录音、生产构建或受限 SDK。

Keep changes scoped, explain behavior and relevant tests. Follow the existing Java style. For translations, preserve resource keys and formatting arguments, test fallback/RTL and include device screenshots only after removing private information. Preserve third-party headers and notices. Avoid changing JNI/runtime artifact versions without documenting ABI/provider compatibility.

Use the Termux build instructions in README. Do not commit .build, .private, libs, generated test classes, model assets or device logs. Security reports follow SECURITY.md, not a public issue containing sensitive material.
